# Root 项目 — 词根拆解工具设计文档

> 日期：2026-08-20
> 状态：设计完成，待实现

## 1. 概述

Root 是一个拉丁语系（西欧语言）单词词根智慧拆解工具。用户输入一个单词，系统自动拆解为前缀、词根、后缀，并以卡片形式展示每个组成部分的详细信息。

## 2. 技术方案

**方案 C：本地优先 + AI 增强（推荐）**

- 本地词根库做第一层快速拆解，常见词即时出结果，离线可用
- 用户输入 API Key 后启用 AI 增强，提供更精准的拆解和详细解释
- 在线模式优先用 AI，API 失败时降级到本地结果

## 3. 功能需求

### 3.1 核心功能

| 功能 | 描述 |
|------|------|
| 自动拆解 | 输入单词后自动触发词根分析，无需按钮 |
| 卡片展示 | 每个词根/前缀/后缀以独立卡片展示 |
| 本地词根库 | 内置 ~600 条词根/前缀/后缀，支持离线拆解 |
| AI 增强 | 通过 API Key 调用 AI 获得更精准拆解和详细解释 |
| 多语言支持 | 主要支持英语，覆盖法语、西班牙语、意大利语等拉丁语系 |
| 同根词导航 | 卡片上的同根词可点击，自动填入输入框并触发新查询 |

### 3.2 卡片内容

每张卡片展示：
- 词根名称（如 `tract-`）
- 含义（中英文，如 "拉，拖 / pull, draw"）
- 来源语言（如 "拉丁语 · trahere"）
- 同根词举例（3-5 个，可点击）
- 类型标签（词根/前缀/后缀）

### 3.3 AI 增强模式

- 与 Summarizer 一致的 API Key 设置面板（localStorage 持久化）
- 启用后 AI 提供更详细的拆解、词源演变、整体含义推导
- 显示整体分析摘要："ex-(向外) + tract-(拉) + -able(能) → 可提取的"

## 5. 技术架构

### 5.1 本地词根库

```javascript
// 词根条目结构
{
  root: "tract",          // 词根
  type: "root",           // root / prefix / suffix
  meaning: "拉，拖",
  meaning_en: "pull, draw",
  origin: "拉丁语",
  from: "拉丁语 trahere",
  examples: ["tractor", "extract", "attract", "contract", "subtract"],
  priority: 1,            // 1普通，2高频，3核心
  languages: ["en", "fr", "es"]  // 适用语言
}
```

**词根库规模：**
- 核心词根 ~300 条（覆盖 80% 常见词）
- 前缀 ~100 条（ex-, re-, pre-, in-, de- 等）
- 后缀 ~150 条（-able, -tion, -ment, -ity 等）
- 扩展词根 ~200 条（中低频）

### 5.2 匹配算法

```
1. 前缀匹配 — 从单词开头匹配最长前缀
2. 词根匹配 — 从剩余部分找最长匹配词根
3. 后缀匹配 — 从剩余尾部匹配最长后缀
4. 未识别部分 — 标注为"未识别片段"
5. AI 增强 — 可选，并行或补充分析
```

### 5.3 AI Prompt

```
分析单词 "{word}" 的词根词源结构。
语言：{language}
要求：
1. 拆解前缀/词根/后缀，每个部分给出含义
2. 给出词源来源（拉丁语/希腊语/古法语等）
3. 给出整体含义的演变逻辑
4. 对每个组成部分给出 2-3 个同根词示例
5. 以 JSON 格式返回
```
